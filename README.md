# Kards Board Weekly

**本项目编写时使用了人工智能工具**

Kards Board Weekly（简称KRBWeekly）是一款*Kards金曲*周榜数据统计工具，使用C#开发。支持手动输入数据或自动获取目标数据并计算分数，内置**修正系数**和**单纯相加**两种算法，适合不同的计算方式

## 核心功能

- 手动数值计算
  
  **手动**输入某视频的增量信息，快速计算得分并导出榜单
- 自动获取数据

  可以**自动**获取带有*Kards金曲*标签类的视频的新增数据并自动计算（**注意：首次运行自动计算时所得数据并非增量**），同时排除不合格的视频，量化规则见下表
  


| 规则 | 时间 | 播放量 |
| :---: | :---: | :---: |
| A | 大于一天且小于七天 | 空 |
| B | 大于七天且小于一个月 | 大于3000 |
| C | 大于一个月且小于半年 | 大于50000 |
| D | 大于半年 | 大于100000 |


- 黑白名单

  指定目标视频进入黑名单，黑名单中的视频即使符合规则也不会被统计。或指定目标视频进入白名单，白名单内的视频即使不符合规则也会被统计

- 算法切换
  
   在设置中，可以在*修正系数模式*和*单纯相加模式*之间切换
