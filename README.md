# Kards Board Weekly

**本项目编写时使用了人工智能工具**

Kards Board Weekly（简称KRBWeekly）是一款*Kards金曲*周榜数据统计工具，使用C#开发。支持手动输入数据或自动获取目标数据并计算分数，内置**修正系数**和**单纯相加**两种算法，适合不同的计算方式

## 核心功能

- 手动数值计算
  
  **手动**输入某视频的增量信息，快速计算得分并导出榜单

  也支持**导入表格**：选 `.xlsx` / `.csv` 文件后，在列映射窗口把播放、收藏、点赞、投币、发布天数、代号分别对应到表格里的某一列（表头能认出来的会自动匹配），确认即按当前系数批量计分。播放列必选，其余不选按 0 计
- 自动获取数据

  可以**自动**获取带有*Kards金曲*标签类的视频的新增数据并自动计算（**注意：首次运行自动计算时所得数据并非增量**）。
  
  搜索标签可在「自动计算」页顶部直接修改（默认 `KARDS金曲`），每次统计跑两轮：精确短语 + 分词兜底

  起算值与统计记录按搜索标签隔离存放（`Data\History\<标签>.json`、`Data\Records\<标签>\`），换标签互不影响；旧版单文件数据会在首次运行时自动迁移到当前标签

  统计前会做两道确认：距上次统计不足 10 分钟时提示可能触发 B 站 412 风控；某个标签还没有起算值时提示本次结果是累计值、需下一周期再统计才是周增量。真的被 412 拦截时会弹窗说明并记下状态，之后 30 分钟内再统计会提前提醒
- 筛选规则集

  只有满足规则集的视频才会参与计分。规则在「设置 → 计算与统计」里编辑，结构与 [ClassIsland](https://github.com/ClassIsland/ClassIsland) 的规则集一致：**条件 → 规则组 → 规则集**三层。

  - 条件：字段（发布时间 / 播放量 / 收藏 / 点赞 / 投币）+ 比较方式（大于、大于等于、小于、小于等于、区间、等于）+ 数值，可点「非」取反
  - 规则组：组内条件按「任一 / 全部」组合，可单独启用、复制、删除
  - 规则集：组间可选「组间任一」或「组间全部」，可整体开关

  默认规则集与旧版 A/B/C/D 过滤表完全等价：


  | 规则组 | 发布时间 | 播放量 |
  | :---: | :---: | :---: |
  | A | 大于一天且小于七天 | 空 |
  | B | 大于等于七天且小于三十天 | 大于3000 |
  | C | 大于等于三十天且小于一百八十天 | 大于50000 |
  | D | 大于等于一百八十天 | 大于100000 |

  关闭规则集或清空所有条件即不做内容筛选
- 黑白名单

  指定目标视频进入黑名单，黑名单中的视频即使符合规则也不会被统计。或指定目标视频进入白名单，白名单内的视频即使不符合规则也会被统计

- 算法切换
  
   在设置中，可以在*修正系数模式*和*单纯相加模式*之间切换
